# Bestiary — 보스 관리 · 도감

MythicMobs 가 실제로 읽는 **파일을 그대로 읽어**, 무엇을 떨구는지 한눈에 보여 주는
관리 도구. 값을 고치면 MythicMobs YAML 에 바로 적히고(원본은 `_backup` 에 남김),
게임 반영만 `/mm reload` 로 합니다.

- **Minecraft** 1.21.4
- **서버** Paper (또는 Paper 계열 포크)
- **Java** 21

---

## 쓰는 법 — `/보스`

| 어디서 | 무엇을 |
|---|---|
| 목록 | **좌클릭** 능력치 고치기 · **우클릭** 스폰 알 · **쉬프트+좌클릭** 드랍 바로 열기 |
| 목록 | 나침반 검색 · 해골단추 보스만 보기 · 쪽 넘기기 |
| 능력치 창 | 체력·피해·방어·이동 속도·밀림 저항·쫓는 거리 — 좌/우클릭으로 오르내리고 **쉬프트로 다섯 배**, **가운데클릭으로 직접 입력** |
| 드랍 창 | 좌/우클릭 확률 ±5% · **쉬프트** ±25% · **가운데클릭** 확률·개수 직접 입력 · **Q** 줄 지우기 |
| 드랍 창 | 아래 가방에서 아이템을 **쉬프트+클릭** 하면 드랍으로 더해집니다 |

- 탭 자동완성: `/보스 <탭>` — 보스부터, 이름과 아이디로 찾습니다.
- 스폰 알: 들고 블록에 우클릭하면 그 자리에 MythicMobs 로 스폰됩니다.
- 드랍 아이콘은 CraftEngine 아이템이면 그 그림을 그대로 보여 줍니다.
- 저장 위치: `plugins/Bestiary/_backup/` 에 고치기 전 원본이 남습니다.

> 2.0.1 — **가운데클릭이 크리에이티브에서 안 먹던 문제** 수정
> (크리에이티브는 `ClickType.CREATIVE`, 생존은 `ClickType.MIDDLE` 로 옵니다).
> 2.0.0 — 드랍 표시·정밀 입력(가운데클릭)·스폰 알·`/보스` 탭 자동완성.

## 명령어 · 권한

| 명령 | 하는 일 |
|---|---|
| `/보스 [낱말\|리로드]` | 목록 열기 · 검색 · MythicMobs 다시 읽기 (`/보스 reload` 도 가능) |

권한은 `bestiary.admin` (기본 op). MythicMobs 와 CraftEngine 은 **소프트 의존**이라
없어도 켜지지만, 없으면 읽을 것이 없습니다.

## 빌드

```
./gradlew build          # build/libs/Bestiary-2.0.1.jar
```

또는 Gradle 없이 바로: `build.ps1` — JDK 21과, 한 단계 위 `libs\` 폴더에
paper-api · adventure jar 가 있으면 됩니다.
